## درباره سامانه

پژوهش‌یار هوشمند یک داور علمی شبیه‌سازی‌شده است: سند پژوهشی شما را استخراج، دسته‌بندی و با روبریک‌های استاندارد ۱۰۰ امتیازی داوری می‌کند؛ ایرادهای روش‌شناختی، آماری، اخلاقی و گزارش‌دهی را با ساختار دقیق ۱۰ جزئی (محل دقیق، توضیح علمی، چرایی اهمیت، راه‌حل گام‌به‌گام و متن پیشنهادی) گزارش می‌کند و برای هر مشکل، راهکار عملی ارائه می‌دهد.

> **اصل صداقت علمی:** سامانه هرگز منبع، داده یا نتیجه نمی‌سازد؛ «یافت‌نشدن» را از «وجود نداشتن» متمایز می‌کند؛ اطلاعات ناقص را «غیرقابل ارزیابی» علامت می‌زند (نه صفر)؛ مشکلات بحرانی را مستقل از امتیاز کل نمایش می‌دهد و جایگزین داوری انسانی مجاز یا تصمیم هیئت تحریریه نیست.

## امکانات

| ماژول | شرح |
| --- | --- |
| داوری پروپوزال | ارزیابی ۱۱ بُعدی با روبریک ۱۰۰ امتیازی قابل تنظیم |
| داوری مقاله | انتخاب خودکار راهنمای گزارش‌دهی متناسب با طرح مطالعه + نمره تبعیت جداگانه |
| ممیزی آماری | تناسب آزمون‌ها، فرض‌ها، توان، مخدوش‌گری، داده گمشده، سازگاری جداول با متن |
| بررسی منابع | راستی‌آزمایی واقعی در **Crossref / OpenAlex / PubMed**؛ کشف DOI نادرست و نشانه Retraction |
| آمادگی انتشار | تطبیق با الزامات مجله هدف + توصیه سردبیری کیفی (بدون ادعای «احتمال پذیرش» جعلی) |
| شبیه‌سازی داوران | ۴ داور مستقل (کارشناس موضوع، متدولوژیست، بیواستاتیستین، سردبیر) + سنتز سردبیری |
| دستیار بازنگری | بازنویسی پیشنهادی با حفظ کامل یافته‌ها + پذیرش/رد/ویرایش |
| گزارش‌ها | گزارش A (نویسندگان) و گزارش B (محرمانه سردبیر) با خروجی **DOCX / HTML قابل چاپ / PDF** |
| نامه پاسخ به داوران | پاسخ point-by-point؛ فقط اصلاحات «واقعاً پذیرفته‌شده» را ادعا می‌کند |
| تاریخچه | جست‌وجو، فیلتر، تغییر نام، حذف، نسخه‌های تحلیل |
| کتابخانه استانداردها | CONSORT 2025، STROBE، PRISMA 2020، SPIRIT، STARD، TRIPOD+AI، CARE، COREQ، SRQR، ARRIVE 2.0، SQUIRE 2.0، CHEERS 2022، ICMJE، COPE، NIH |

**پشتیبانی اسناد:** PDF متنی، DOCX، TXT، MD، RTF و داده مکمل XLSX — فارسی، انگلیسی و دوزبانه. فایل‌های DOC قدیمی و تصاویر اسکن‌شده (OCR) به‌صورت صریح اعلام می‌شوند؛ هرگز بی‌صدا نادیده گرفته نمی‌شوند.

## معماری فنی

- **Next.js 16 (App Router) + TypeScript** — رابط کاربری تک‌صفحه‌ای با مسیریابی hash
- **Tailwind CSS 4 + shadcn/ui + Recharts** — طراحی آکادمیک سرمه‌ای/فیروزه‌ای، فونت وزیرمتن، RTL کامل
- **Prisma + SQLite** — بدون نیاز به سرویس خارجی؛ فایل‌های آپلودی در `db/uploads/`
- **پردازش هوش مصنوعی فقط سمت سرور** — کلید API هرگز در مرورگر قرار نمی‌گیرد
- موتورهای مستقل و قابل تست: `classification`، `proposal`، `manuscript`، `stats`، `references`، `journal`، `reviewers`، `reports`، `revision`

```
src/
├── app/
│   ├── page.tsx                    # اپلیکیشن تک‌صفحه‌ای (SPA)
│   ├── layout.tsx                  # RTL، فونت وزیرمتن
│   └── api/
│       ├── projects/               # CRUD + آپلود + استخراج
│       │   └── [id]/classify | review | references | revisions | response-letter | export | print
│       ├── settings/               # وزن‌های روبریک
│       └── health/
├── lib/
│   ├── ai.ts                       # لایه هوش مصنوعی (سازگار با OpenAI) + تعمیرگر JSON
│   ├── extract.ts                  # استخراج PDF/DOCX/RTF/TXT/XLSX + تشخیص زبان
│   ├── engines/                    # پرامپت‌ها و منطق ۹ موتور داوری
│   ├── guidelines.ts               # کتابخانه استانداردها (قابل گسترش)
│   ├── rubrics.ts                  # روبریک‌های پیش‌فرض
│   ├── scoring.ts                  # موتور امتیازدهی شفاف با نرمال‌سازی
│   ├── schemas.ts                  # اسکیماهای Zod برای خروجی ساختاریافته
│   ├── docx-export.ts              # تولید گزارش DOCX با RTL
│   └── print-html.ts               # گزارش HTML قابل چاپ/PDF
└── components/app/                 # کامپوننت‌های رابط کاربری
```

ساختارهای جانبی: `android/` (اپ بومی اندروید)، `.github/workflows/android-build.yml` (ساخت خودکار APK)، `Dockerfile` (استقرار)، `public/manifest.webmanifest` + `sw.js` (PWA)، `scripts/` (آیکون‌ساز و ابزارها).

## راه‌اندازی سریع

```bash
# پیش‌نیاز: Node.js 20+ (یا Bun)
git clone https://github.com/zappata7927-cpu/researchmate-ai.git
cd researchmate-ai

# ۱) نصب وابستگی‌ها
npm install        # یا: bun install

# ۲) تنظیم متغیرهای محیطی
cp .env.example .env
# سپس AI_BASE_URL، AI_API_KEY و AI_MODEL را در .env تنظیم کنید

# ۳) ساخت پایگاه‌داده
npx prisma db push

# ۴) اجرا
npm run dev        # http://localhost:3000
```

### پیکربندی سرویس هوش مصنوعی

سامانه با هر سرویس سازگار با OpenAI API کار می‌کند:

```env
AI_BASE_URL=https://api.openai.com/v1        # یا https://api.z.ai/api/paas/v4 یا http://localhost:11434/v1
AI_API_KEY=your-key
AI_MODEL=gpt-4o                              # یا glm-4.6 / llama3 / ...
```

توجه: برای تحلیل اسناد، مدل باید از فارسی پشتیبانی کند و خروجی JSON بلند بدهد (مدل‌های کلاس GLM-4.6، GPT-4o و هم‌تراز توصیه می‌شوند).

## استقرار سرور (خودتان میزبانی کنید)

اپ اندروید و PWA به یک سرور زنده نیاز دارند. سه مسیر رایج:

**الف) Docker (سرور شخصی/VPS):**

```bash
docker build -t researchmate-ai .
docker run -d --name researchmate -p 3000:3000 -v researchmate_data:/app/db \
  -e AI_BASE_URL="https://api.z.ai/api/paas/v4" \
  -e AI_API_KEY="..." -e AI_MODEL="glm-4.6" \
  researchmate-ai
```

**ب) Railway / Render (بدون سرور):** مخزن را وصل کنید؛ Build = `npm install && npm run build`، Start = `npx prisma db push --skip-generate --accept-data-loss && node .next/standalone/server.js` و یک Volume روی `/app/db` ببندید تا پایگاه‌داده باقی بماند.

**ج) VPS با pm2:**

```bash
npm install && npx prisma db push && npm run build
HOSTNAME=0.0.0.0 PORT=3000 pm2 start .next/standalone/server.js --name researchmate
```

> اگر HTTPS ندارید، از reverse proxy با گواهی معتبر (مثلاً Caddy) استفاده کنید — اپ اندروید فقط به `https` متصل می‌شود.

## نسخه اندروید (APK)

پوشه `android/` یک اپ بومی اندروید (WebView امن) است که به سرور شما وصل می‌شود و آپلود فایل، دانلود گزارش‌ها و بازکردن گزارش‌های قابل چاپ در مرورگر را به‌صورت بومی پشتیبانی می‌کند. **آدرس سرور از داخل خود اپ** (منوی سه‌نقطه ← «تغییر آدرس سرور») قابل تغییر است و نیازی به بیلد مجدد نیست.

**سه راه دریافت APK:**

1. **دانلود آماده (Release):** [ResearchMate-AI-Android-v1.0.0.apk](https://github.com/zappata7927-cpu/researchmate-ai/releases/download/v1.0.0/ResearchMate-AI-Android-v1.0.0.apk) را نصب کنید (اندروید ۷ به بالا؛ نسخهٔ امضاشدهٔ release).
2. **ساخت خودکار در GitHub Actions:** به تب **Actions → Build Android APK** بروید و Artifact با نام `ResearchMate-AI-Android` را دانلود کنید. با هر تغییر در پوشه `android/`، APK تازه ساخته می‌شود.
3. **بیلد محلی:**

```bash
cd android
./gradlew assembleDebug      # خروجی: app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease    # خروجی: app/build/outputs/apk/release/app-release.apk (امضاشده با کلید دیباگ همان دستگاه)
```

> پیش‌فرضِ آدرس سرور در `MainActivity.java` (ثابت `DEFAULT_SERVER_URL`) قرار دارد؛ برای انتشار عمومی آن را به دامنه خودتان تغییر دهید یا همان منوی داخل اپ را به کاربران توصیه کنید.

### نصب به‌صورت PWA (بدون APK — سریع‌ترین راه)

سایت را با Chrome اندروید باز کنید ← منوی سه‌نقطه ← **«افزودن به صفحه اصلی» (Add to Home screen)**. اپ با آیکون اختصاصی، تمام‌صفحه و با میان‌برهای «داوری پروپوزال / مقاله / ممیزی آماری» نصب می‌شود و همیشه آخرین نسخه سرور را اجرا می‌کند. همین قابلیت روی iOS (Safari ← Add to Home Screen) و دسکتاپ (Chrome/Edge ← Install) هم کار می‌کند.

## طراحی و امتیازدهی

- امتیاز هر معیار ۰ تا ۵ است (۰ = فاقد، ۵ = عالی) و با وزن‌ها به ۱۰۰ تبدیل می‌شود.
- وزن‌های روبریک از صفحه «تنظیمات» بر اساس الزامات دانشگاه/نهاد مالی شما قابل تغییر است.
- اگر معیاری قابل ارزیابی نباشد، «غیرقابل ارزیابی» می‌شود و جمع وزن‌ها فقط بین معیارهای قابل ارزیابی نرمال می‌شود؛ تعداد معیارهای قابل ارزیابی همیشه نمایش داده می‌شود.
- وجود مشکل بحرانی اخلاقی/روش‌شناختی، مستقل از امتیاز کل هشدار داده می‌شود.

## حریم خصوصی

- اسناد فقط روی سرور خودِ نصب ذخیره می‌شوند و برای آموزش مدل‌ها استفاده نمی‌شوند.
- هر پروژه به‌صورت کامل و بدون بازگشت قابل حذف است.
- رعایت اصول رازداری داوری ICMJE و COPE در تفکیک گزارش نویسندگان (A) و گزارش محرمانه سردبیر (B).
- پیش از پردازش منابع محرمانه ارسالی به مجلات، سیاست AI داوری همان مجله را رعایت کنید.
